# Haxe setup for Raspberry Pi

```CompleteHaxeLimeInstall_Menu_RPi.sh```

Follow the menu

## Features

- Install Docker (required for Haxe installation)
- Install Haxe 4.3.7 (latest stable) from Docker
- Install older Haxe versions from Docker
- Install Haxe from archived binaries
- Enable Hxcpp Compile Cache (Experimental)

## Installation

Run the script and follow the interactive menu:

```bash
./CompleteHaxeLimeInstall_Menu_RPi.sh
```

## Note about Haxe 4.3.7

The Haxe 4.3.7 binaries archive (`haxe-binaries-4.3.7.tgz`) will be automatically created the first time you install Haxe 4.3.7 using option 2. This archive can then be used for faster installations via option 4 without needing Docker.
